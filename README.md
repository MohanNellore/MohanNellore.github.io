# Mohan Nellore: Data Analyst Portfolio

Personal portfolio website, hosted free with GitHub Pages at **https://mohannellore.github.io**.

It introduces me as an aspiring data analyst and showcases my projects, skills, internship, certifications and contact details.

## Sections

- **Home**: introduction and links to LinkedIn and GitHub
- **About**: summary, core skills and tools
- **Resume**: internship experience, education and certifications
- **Projects**: data analytics projects with the key finding of each
  - [Uber Trip Analysis](https://github.com/MohanNellore/Uber-Trip-Analysis) (Power BI)
  - [Electric Vehicle Analysis](https://github.com/MohanNellore/Electric-Vehicle-Analysis) (Python, Power BI)
  - [Store Sales and Profit Analysis](https://github.com/MohanNellore/sales-profit-analysis) (Python)
  - [Telco Customer Churn Analysis](https://github.com/MohanNellore/Customer-Churn-Analysis) (Python)
  - [RAG Document Q&A](https://github.com/MohanNellore/rag-document-qa) (Python, Streamlit)
- **Contact**: message form (Formspree)

## Built with

- HTML, CSS and JavaScript (Bootstrap based template)
- Google Analytics for visit and click tracking
- Formspree for the contact form
- GitHub Pages for hosting

## Run it locally

No build step is needed. From the project folder run:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in a browser.

## Project structure

```
MohanNellore.github.io/
├── index.html      # the whole site
├── css/            # styles (Bootstrap, template styles)
├── js/             # scripts and plugins
├── fonts/          # icon fonts
├── images/         # photos and project card images
├── scss/           # template source styles

```
