GCP air-quality data pipeline

Python, Pandas, Cloud Storage, BigQuery, SQL

A batch ETL pipeline that cleans a messy CSV of daily city air-quality readings with Pandas, checks it against data-quality rules, stages it in Cloud Storage, and loads it into BigQuery. The table is partitioned by reading date and clustered by city. Five SQL queries using CTEs and window functions analyze the result.

The run stops when a quality check fails, so bad data never reaches the warehouse. The same pipeline also runs locally on SQLite, so it works without a cloud account. The data is synthetic, generated with deliberate errors such as duplicates, negative values, and invalid dates.
